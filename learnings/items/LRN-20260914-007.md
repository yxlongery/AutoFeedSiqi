# 版本号建议与前台运行硬约定

（自 AutoFeedEmby LRN-20260819-003 移植，已落本库 AGENTS.md）

### Summary
两条硬约定：① 每次 git 收尾 `feat` 自动升 minor（`nbgv set-version X.Y` 随功能同 commit），升版当天当版打 tag + 部署；② 耗时脚本必须前台运行，禁 nohup 静默后台或吞输出。

### Details
- `feat` 即升 minor 信号，无需建议等待，直接执行；同会话多 feat 只升一次；major 破坏性变更须用户明确确认。
- patch（修复/重构/文档）自动递增，无需改 version.json；纯文档提交经 pathFilters 排除不计数。
