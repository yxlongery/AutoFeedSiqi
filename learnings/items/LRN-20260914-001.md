# NAS Docker 部署脚本化核心踩坑

（自 AutoFeedEmby LRN-20260813-003 移植，Siqi 化）

### Summary
Siqi 部署链照搬 Emby：`-r` 发布瘦身 + base/update 分层 + ssh tar 流式解包 + push 被墙容错 + nbgv 打 tag。首部实测 base 43M（双架构）、update 32M/31M。

### Details
- `dotnet publish -c Release -r linux-x64/-arm64`（framework-dependent）双架构并行；一次 restore 经环境变量传全部 RID，避免并发 restore 争写。
- Docker 分层：base（依赖 dll + libe_sqlite3.so + appsettings.json，长期不变）+ update（应用本体 + wwwroot + 差异）。组装批量走 tar 管道一次复制，禁逐文件 mkdir/cp。
- NAS 上传：clouddrive2 传多小文件不稳；本地打 tar.gz 单包，ssh 远端流式解包。
- Hub push 被墙：dockerd 已配 proxies 出海；push 失败仅警告，`compose up -d` 先用本地镜像，不影响服务。
- 打 tag 一律 `git tag v$(nbgv get-version -v SimpleVersion) HEAD`，勿用 `nbgv tag`（LibGit2Sharp 引擎与构建差 1）；取版本务必 `-v SimpleVersion`（`-v Version` 会拼出四段错误 tag）。
- 常规模式 diff 用 G 盘 `G:/fnOS/docker/autofeedsiqi/Dockerfile/base` 作基准。

### Suggested Action
已落地 `scripts/deploy-nas.sh`。普通版本走增量；依赖升级/清理残留/首次部署才 `--rebuild-base`。
