# 镜像多架构发布完整链路

（自 AutoFeedEmby LRN-20260813-008 移植，Siqi 化）

### Summary
`yxlonger/autofeedsiqi` 双架构（amd64+arm64）发布链路：dockerd proxies 出海 + 内置 buildkit 分架构构建 + 单平台 push + imagetools 合并 manifest。

### Details
- 产物分层按架构：`base|update/{amd64,arm64}`；Dockerfile 用 `ARG TARGETARCH` + `COPY base/${TARGETARCH}`（buildx TARGETARCH 恰为 amd64/arm64，无需映射）。
- Hub 凭证在 NAS `~/.docker/config.json`（base64(user:access_token)），**勿用 `docker login`**（dockerd 无代理直连超时）。
- 关键教训：`docker-container` 驱动注入的 env 代理只对 RUN 生效，registry oauth 仍直连超时；改用 dockerd 内置 buildkit（docker driver）分架构构建（纯 COPY 无 RUN 无需 QEMU）+ 单平台 push（dockerd proxies 出海）+ `buildx imagetools create`（客户端进程读 env 代理）合并 multi-arch manifest。
- tag 策略：Hub 只留 `latest` / `vX.Y.Z`（multi-arch）+ `latest-amd64/latest-arm64`（滚动单平台）；版本级单平台 tag 不上 Hub。

### Suggested Action
已落地 `scripts/nas-deploy.sh`。新增架构改 `RID_ARCHS`；dockerd 代理丢失重写 daemon.json proxies。
