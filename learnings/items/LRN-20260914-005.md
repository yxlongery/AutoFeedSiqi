# nbgv 两段与三段版本号的高度差异

（自 AutoFeedEmby LRN-20260815-006 移植；Siqi 实证：`set-version 1.3` → 首版 1.3.1）

### Summary
`version.json` 两段 `X.Y` → 高度落第三段（patch 随提交自增，首版 X.Y.1）；三段 `X.Y.0` → 高度落第四段（SimpleVersion 恒 X.Y.0，后续提交版本不可区分、再打 tag 冲突）。

### Details
- 根因（nbgv 源码 `SemanticVersion.cs` `VersionHeightPosition`）：`Version.Build == -1`（两段）→ Position.Build；三段 → Position.Revision。
- 三段危害：tag 后任何计入提交只递增第四段，SimpleVersion 恒定，与"发布=打 tag、patch 自动递增"机制相悖。恢复：改回两段提交即可（position 移动自动重置高度）。

### Suggested Action
升 minor 一律 `nbgv set-version X.Y`（两段）；打 tag 前 `nbgv get-version -v SimpleVersion` 复核 patch 随提交递增。
