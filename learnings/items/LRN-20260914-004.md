# deploy 脚本在 bash 工具下提前返回

（自 AutoFeedEmby LRN-20260816-013 / LRN-20260903-003 移植，两条同机理合并，Siqi 化）

### Summary
`deploy-nas.sh` 在 opencode bash 工具下若对调用加管道（`| tail`/`| tee`）或后台化（`&`/`setsid`/`nohup`），工具在调用返回时杀整个进程组，脚本内 `dotnet publish &` 子进程被杀、`wait` 非零，`set -e` 下断在 1/5 publish。Siqi 首部 v1.2.1 前台单次跑通 86s，印证非脚本缺陷，属调用纪律。

### Details
- 规范调用：`bash scripts/deploy-nas.sh vX.Y.Z --yes`（或自动 `bash scripts/deploy-nas.sh --yes`），**无管道、无后台、超时 ≥600000ms**；进度以 `.deploy-logs/` 落盘日志为准（脚本内置 tee）。
- 判完成只认「部署完成: vX.Y.Z」字样；调用发出后全程挂起，中途不发其他 bash 调用、不提前返回。
- 中断幂等续跑：用已有 tag `bash scripts/deploy-nas.sh vX.Y.Z --yes`（自动模式会因 tag 已存在拒绝，重跑必传显式版本）。
