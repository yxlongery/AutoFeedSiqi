# base 层纯依赖瘦身与应用本体归属

（自 AutoFeedEmby LRN-20260813-009 移植，Siqi 化）

### Summary
base = 纯依赖（`*.dll` 除 `AutoFeedSiqi*.dll` + `libe_sqlite3.so` + `appsettings.json`），长期不变；update = 应用本体 + wwwroot + 差异。Siqi 首部实测 base 43M（双架构）、update 32M/31M，二次发布 base 全部 CACHED 秒传。

### Details
- `is_base_file()`：项目 dll（`AutoFeedSiqi*.dll`）永远走 update；`skip_waste()` 精确排除 apphost/pdb/exe/web.config/appsettings.Development.json。
- 血泪：`skip_waste` 勿用 `AutoFeedSiqi.*` 通配（会把应用本体 dll 一并扔掉，增量包缺主 dll）。本库首版即精确排除，未踩坑。
- `--rebuild-base` 触发标准：仅依赖升级/清理残留/首次部署。
