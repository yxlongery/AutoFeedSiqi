# 容器 DataProtection 密钥持久化

- **来源**：Siqi v1.2.1 首部部署日志 + 移植 Emby TD-20260813-A01，2026-09-14
- **问题/计划**：容器启动报 `Storing keys in '/root/.aspnet/DataProtection-Keys'`（容器内非挂载目录），容器重建后密钥丢失。方案（Emby 已验证）：`Program.cs` 加 `AddDataProtection().PersistKeysToFileSystem(Path.Combine("data", "dataprotection"))` + `SetApplicationName("AutoFeedSiqi")`，复用 `./data:/app/data` 现有卷，零改动 compose/脚本。
- **验证口径**：部署后 `docker logs autofeedsiqi | grep -i dataprotection` 无警告；`./data/dataprotection/` 有 key 文件；容器重建后 key 不变。
