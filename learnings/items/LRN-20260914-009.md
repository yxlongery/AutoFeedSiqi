# SQLite AUTOINCREMENT 序列复位

（自 AutoFeedEmby LRN-20260819-006 移植，通用机理）

### Summary
SQLite `AUTOINCREMENT` 表删行后 id 不回落（`sqlite_sequence` 记录已分配最大 id）；清理测试数据后须核对并复位 seq。

### Details
- 机理：下次插入取 `max(seq, 现有 max(id)) + 1`；删掉最大 id 后新插入仍继续递增。
- 复原：删完测试行后 `UPDATE sqlite_sequence SET seq = <删前最大> WHERE name = '<表名>';`（seq 不得小于现存 max(id)）。
- 取证：`SELECT sql FROM sqlite_master WHERE type='table' AND name='<表名>';` 确认是否 AUTOINCREMENT。
