# 升 minor 先提交再打 tag

（自 AutoFeedEmby LRN-20260820-004 移植；Siqi 实证：`8d0618f` 先提交 version.json 再取到 1.3.1）

### Summary
`nbgv set-version X.Y` 后（未提交、高度=0）取 SimpleVersion 拿到的是假想 `X.Y.0`；提交后该 commit 才是高度线第 1 个提交，实际 `X.Y.1`。未提交就打 tag 会导致 tag 名与构建版本脱节。

### Details
- 根因：NBGV 版本号 = version.json 主段 + git height，tag 只是输出标记（"No dependency on tags"）；两段写法下 version.json 提交本身计入高度。
- 正确顺序：① commit 代码与 version.json（一个逻辑单元）→ ② `git tag v$(nbgv get-version -v SimpleVersion) HEAD` → ③ 复核 `NuGetPackageVersion` 无 `-g{hash}` 杂质（脏工作区会注入杂质）。
- 本库发布由 `deploy-nas.sh` 自动模式统一打 tag/push/核对，无需手工打；`AssemblyInformationalVersion` 带 `+g{hash}` 属 NBGV 设计，勿误判。
